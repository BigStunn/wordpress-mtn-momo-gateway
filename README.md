# WordPress MTN Mobile Money & Orange Money Payment Gateway

A custom WordPress payment gateway plugin developed to enable students to purchase online courses using MTN Mobile Money and Orange Money on a live e-learning platform in Cameroon.

## Project Overview

I developed this plugin to provide a convenient way for students to pay for online courses directly through an e-learning website using local mobile money payment methods.

The plugin was tested on a live e-learning platform, where students can make course purchases using MTN Mobile Money or Orange Money and receive access to their purchased courses through their website accounts.

## Key Features

- MTN Mobile Money payment support.
- Orange Money payment support.
- Integration with an online course purchasing workflow.
- Payment processing for students purchasing online courses.
- Course access linked to the purchase process on the e-learning platform.
- Custom WordPress plugin functionality developed for the platform's requirements.

## Technologies

- WordPress
- PHP
- Mobile money payment integrations
- WordPress plugin development
- E-learning and online course purchasing workflows

## Real-World Application

This plugin was tested on a live e-learning website to support online course purchases using MTN Mobile Money and Orange Money.

It demonstrates practical experience building custom WordPress functionality, integrating payment methods, and connecting payment workflows with course purchasing and student accounts.
